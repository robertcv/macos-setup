Get slovenian keayboard layout from https://github.com/smlu/macos-slovenian-keyboard-layout

Installation
1. Copy file Slovenian - QWERTZ.kaylayout into Library/Keyboard Layouts/
2. Got into System Preferences > Keyboard > Input Sources > + > Others > Slovenian - QWERTZ > Add
3. Choose Slovenian - QWERTZ as current keyboard layout from the macOS menu bar
